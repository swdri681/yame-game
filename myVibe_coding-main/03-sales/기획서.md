# CSV 매출 데이터 통합 프로그램 기획서

## 1. 프로그램 목적

`csv` 폴더 바로 아래에 있는 모든 CSV 파일의 매출 데이터를 하나로 모아 `매출.xlsx` 파일의 `매출` 시트에 입력합니다.

작업 중 오류가 발견되면 일부 데이터만 반영되는 일을 막아야 합니다. 따라서 모든 CSV 파일과 작업 조건을 먼저 검사하고, 검사를 모두 통과한 경우에만 엑셀 파일을 변경합니다. 엑셀 파일이 정상적으로 저장된 뒤에만 처리한 CSV 파일을 `completed` 폴더로 이동합니다.

## 2. 사용 기술

- Python: 프로그램 실행과 전체 처리 순서 관리
- Python 기본 모듈
  - `csv`: CSV 파일 읽기
  - `pathlib`: 파일과 폴더 경로 처리
  - `shutil`: CSV 파일 이동
  - `tempfile` 또는 임시 파일 경로: 엑셀 저장 결과 사전 확인
- `openpyxl`: 기존 `매출.xlsx` 파일을 열고 셀 값을 변경한 뒤 저장

## 3. 파일 구조

```text
03-sales/
├─ 기획서.md
├─ 매출.xlsx
├─ csv/
│  ├─ 대전_2026_10.csv
│  ├─ 대전_2026_11.csv
│  └─ ...
└─ completed/
   └─ 처리 완료된 CSV 파일
```

- 프로그램 파일을 나중에 작성할 경우 `03-sales` 폴더 바로 아래에 둡니다.
- 읽기 대상은 `03-sales/csv` 바로 아래에 있고 확장자가 `.csv`인 파일만 해당합니다.
- `csv` 안의 하위 폴더와 CSV가 아닌 파일은 처리하지 않습니다.
- `completed` 폴더가 없으면 모든 사전검사를 통과한 뒤 생성합니다.
- `매출.xlsx`의 다른 시트는 읽거나 수정하지 않습니다.

## 4. 입력 파일 기준

### 4.1 CSV 파일

- 각 CSV 파일의 첫 번째 행은 열 제목입니다.
- CSV 열 제목과 열 순서는 `매출.xlsx`의 `매출` 시트 1행과 정확히 같아야 합니다.
- 현재 확인한 제목은 다음 16개입니다.

```text
매출일, 영업소, 영업담당, 기간, 전표번호, 상품코드, 상품명, 대분류,
중분류, 소분류, 거래처코드, 거래처명, 매출수량, 매출금액, 매출이익, 단가
```

- 첫 행 아래의 행들만 실제 매출 데이터로 사용합니다.
- 여러 CSV의 데이터는 모두 합쳐서 한 번에 입력합니다.
- 처리 결과를 다시 확인하기 쉽도록 CSV 파일 이름의 오름차순으로 읽고, 각 파일 안에서는 기존 행 순서를 유지합니다.

### 4.2 엑셀 파일

- 대상 파일은 `03-sales/매출.xlsx`입니다.
- 대상 시트 이름은 정확히 `매출`이어야 합니다.
- `매출` 시트의 1행은 제목 행이므로 값과 서식을 모두 유지합니다.
- `매출` 시트의 2행부터 기존 마지막 데이터 행까지는 셀의 값만 지웁니다.
- 행 높이, 열 너비, 글꼴, 색상, 테두리, 표시 형식 등 기존 셀 서식은 유지합니다.
- 새 데이터가 기존 데이터보다 많아 서식이 없는 행까지 내려가면, 바로 위 데이터 행의 셀 서식을 같은 열에 복사합니다. 값이나 수식은 복사하지 않습니다.
- `매출` 이외의 시트는 값과 서식을 모두 그대로 유지합니다.

## 5. 전체 처리 순서

### 1단계: 작업 경로 확인

1. 프로그램이 있는 위치를 기준으로 `매출.xlsx`, `csv`, `completed` 경로를 만듭니다.
2. 현재 작업 폴더가 달라도 같은 파일을 찾을 수 있도록 고정된 상대 경로를 사용합니다.

### 2단계: 대상 CSV 목록 만들기

1. `csv` 폴더 바로 아래에서 확장자가 `.csv`인 파일을 찾습니다.
2. 파일 이름 오름차순으로 정렬합니다.
3. CSV 파일이 하나도 없으면 작업을 중단하고 이유를 알립니다.

### 3단계: 변경 없이 전체 사전검사

이 단계에서는 엑셀, CSV, `completed` 폴더를 변경하지 않습니다.

1. `매출.xlsx` 파일이 존재하고 읽을 수 있는지 확인합니다.
2. 엑셀 파일 안에 `매출` 시트가 있는지 확인합니다.
3. `매출` 시트 1행에 제목이 있는지 확인합니다.
4. 모든 CSV 파일을 열 수 있는지 확인합니다.
5. 각 CSV가 빈 파일이 아닌지 확인합니다.
6. 각 CSV의 첫 행 제목과 열 순서가 엑셀 1행과 정확히 같은지 확인합니다.
7. 각 데이터 행의 열 개수가 제목의 열 개수인 16개와 같은지 확인합니다.
8. 읽기 도중 깨진 문자나 CSV 형식 오류가 발생하지 않는지 확인합니다.
9. `completed` 폴더에 옮길 파일과 같은 이름의 파일이 이미 있는지 모두 확인합니다.
10. 같은 이름의 파일이 하나라도 있으면 덮어쓰지 않고 전체 작업을 중단합니다.
11. 검사한 모든 CSV 데이터는 메모리에 모아 둡니다.

CSV 파일 하나에서라도 오류가 발견되면 나머지 파일까지 변경하지 않고 종료합니다. 오류 메시지에는 문제가 발생한 파일 이름, 가능한 경우 행 번호, 오류 이유를 표시합니다.

### 4단계: 엑셀 데이터 갱신

모든 사전검사를 통과한 경우에만 진행합니다.

1. `openpyxl`로 `매출.xlsx`를 엽니다.
2. `매출` 시트 2행부터 기존 마지막 데이터 행까지 셀의 값만 `None`으로 바꿉니다.
3. 모아 둔 CSV 데이터를 `매출` 시트 2행부터 차례대로 입력합니다.
4. 날짜와 숫자는 엑셀에서 사용할 수 있는 알맞은 자료형으로 변환합니다.
5. 기존 셀 서식은 바꾸지 않습니다.
6. 새 데이터가 기존 서식 범위를 넘으면 직전 데이터 행의 서식만 복사합니다.
7. 제목이 있는 1행과 다른 시트는 수정하지 않습니다.

### 5단계: 엑셀 안전 저장

1. 변경한 통합 문서를 먼저 같은 폴더의 임시 엑셀 파일에 저장합니다.
2. 임시 파일을 다시 열어 `매출` 시트와 입력 행 수를 확인합니다.
3. 임시 파일 저장이나 재검사에 실패하면 원본 `매출.xlsx`를 바꾸지 않고 종료합니다.
4. 임시 파일이 정상이면 원본 `매출.xlsx`를 임시 파일로 교체합니다.
5. 교체가 완료되어야 엑셀 저장 성공으로 판단합니다.

이 방식은 저장 도중 프로그램이 멈춰 원본 엑셀 파일이 손상될 위험을 줄이기 위한 것입니다.

### 6단계: CSV 완료 폴더 이동

1. 엑셀 저장 성공 후 `completed` 폴더가 없으면 생성합니다.
2. 이번에 읽은 CSV 파일을 `csv` 폴더에서 `completed` 폴더로 이동합니다.
3. 파일을 덮어쓰는 기능은 사용하지 않습니다.
4. 이동 중 오류가 발생하면 즉시 중단하고, 이동된 파일과 이동되지 않은 파일을 오류 메시지로 알립니다.
5. 엑셀 저장에 실패한 경우 CSV는 한 개도 이동하지 않습니다.

## 6. 오류 처리 기준

| 오류 상황 | 처리 방법 | 엑셀 변경 | CSV 이동 |
|---|---|---:|---:|
| `csv` 폴더가 없음 | 오류 메시지 출력 후 종료 | 안 함 | 안 함 |
| CSV 파일이 없음 | 처리할 파일이 없다고 알리고 종료 | 안 함 | 안 함 |
| `매출.xlsx`가 없음 | 오류 메시지 출력 후 종료 | 안 함 | 안 함 |
| `매출` 시트가 없음 | 오류 메시지 출력 후 종료 | 안 함 | 안 함 |
| CSV를 읽을 수 없음 | 파일 이름과 오류를 알리고 종료 | 안 함 | 안 함 |
| CSV 제목 또는 열 순서 불일치 | 기대 제목과 실제 제목을 알리고 종료 | 안 함 | 안 함 |
| CSV 데이터 행의 열 개수 불일치 | 파일 이름과 행 번호를 알리고 종료 | 안 함 | 안 함 |
| `completed`에 같은 이름이 있음 | 해당 파일 이름을 알리고 전체 종료 | 안 함 | 안 함 |
| 임시 엑셀 저장 또는 재검사 실패 | 임시 파일을 정리하고 종료 | 안 함 | 안 함 |
| 원본 엑셀 교체 실패 | 오류 메시지 출력 후 종료 | 안 함 | 안 함 |
| 엑셀 저장 후 CSV 이동 실패 | 이동 상태와 실패 파일을 알리고 종료 | 저장됨 | 일부 이동 가능 |

### 주의할 예외

- 엑셀 파일을 Excel 프로그램에서 열어 둔 경우 저장 또는 교체가 실패할 수 있습니다. 실행 전에 `매출.xlsx`를 닫아야 합니다.
- 엑셀 저장이 끝난 뒤 운영체제 권한이나 저장장치 문제로 CSV 이동이 실패할 수 있습니다. 이 경우 엑셀은 이미 갱신되었지만 CSV는 일부만 이동되었을 수 있으므로 오류 메시지를 확인해야 합니다.
- CSV의 문자 인코딩, 날짜 형식, 숫자 안의 쉼표 처리 기준은 실제 프로그램 작성 전에 샘플 파일을 기준으로 확정해야 합니다. 확인되지 않은 형식을 임의로 정상 처리하지 않습니다.
- `openpyxl`은 엑셀의 일부 고급 기능이나 외부 연결을 완전히 보존하지 못할 수 있습니다. 실제 프로그램 작성 시 원본 복사본으로 저장·재열기 시험이 필요합니다.

## 9. 검산 방법

숫자가 포함된 결과는 다음 방식으로 확인합니다.

1. 각 CSV에서 제목 행을 제외한 데이터 행 수를 셉니다.
2. 모든 CSV의 데이터 행 수를 더해 `예상 데이터 행 수`를 구합니다.
3. 저장된 `매출.xlsx`를 다시 열어 `매출` 시트 2행부터 실제 데이터가 있는 행 수를 셉니다.
4. `예상 데이터 행 수`와 `실제 데이터 행 수`가 같은지 비교합니다.
5. 입력 시작 행이 2행이므로 마지막 데이터 행 번호는 `예상 데이터 행 수 + 1`인지 확인합니다.
6. 처리 대상 CSV 파일 수와 `completed`로 이동된 파일 수가 같은지 비교합니다.
