# 벽돌깨기 프로그램 기획서

## 1. 프로젝트 개요

- 프로젝트명: 자바스크립트 벽돌깨기
- 목적: HTML, CSS, 자바스크립트를 분리하여 키보드로 조작할 수 있는 기본 벽돌깨기 게임을 제작합니다.
- 실행 환경: 1024 × 768 해상도의 데스크톱 모니터와 최신 웹 브라우저를 기준으로 합니다.
- 저장 위치: `vibe-class/02-bricks`

## 2. 확정 사양

### 2.1 화면 구성

- 게임 화면의 전체 크기는 1024 × 768 모니터에서 스크롤 없이 보이도록 구성합니다.
- 실제 게임 영역은 브라우저의 주소창과 여백을 고려하여 `960px × 680px`로 설정하고 화면 가운데에 배치합니다.
- 게임 영역의 배경색은 흰색으로 설정합니다.
- 게임 영역의 경계를 알아볼 수 있도록 얇은 회색 테두리를 표시합니다.
- 점수와 게임 상태 안내 문구를 게임 영역 상단에 표시합니다.

### 2.2 벽돌

- 벽돌은 7개 층으로 구성합니다.
- 한 층에는 벽돌 9개를 배치하여 총 63개로 구성합니다.
- 벽돌 한 개의 크기는 `가로 100px × 세로 30px`로 설정합니다.
- 벽돌 사이의 간격은 가로·세로 각각 `5px`로 설정합니다.
- 벽돌 색상은 빨간색으로 통일합니다.
- 공과 충돌한 벽돌은 즉시 사라지고 점수 10점을 추가합니다.

### 2.3 사용자 컨트롤 바

- 사용자 컨트롤 바의 크기는 `가로 150px × 세로 15px`로 설정합니다.
- 색상은 검은색으로 설정합니다.
- 게임 영역 아래쪽에 배치합니다.
- 키보드의 왼쪽·오른쪽 방향키로 이동합니다.
- 컨트롤 바는 게임 영역 밖으로 나가지 않습니다.

### 2.4 공

- 공은 지름 `16px`의 원으로 표시합니다.
- 공 색상은 파란색으로 설정하여 흰색 배경과 빨간 벽돌에서 쉽게 구분되도록 합니다.
- 게임 시작 전에는 공을 컨트롤 바 위에 정지시킵니다.
- 게임 시작 후 공은 일정한 속도로 대각선 방향으로 움직입니다.
- 공이 게임 영역의 왼쪽·오른쪽·위쪽 벽, 컨트롤 바 또는 벽돌에 닿으면 진행 방향을 바꿉니다.

### 2.5 게임 진행

1. 페이지를 열면 게임은 대기 상태로 시작합니다.
2. 화면에 `스페이스키를 눌러 게임을 시작하세요.`라는 안내를 표시합니다.
3. 사용자가 스페이스키를 누르면 공이 움직이면서 게임이 시작됩니다.
4. 모든 벽돌을 제거하면 승리 화면과 최종 점수를 표시합니다.
5. 한 번 실행할 때 총 3회의 게임 기회를 제공합니다.
6. 공이 화면 아래로 떨어지면 현재 게임이 끝나고 남은 기회를 1회 차감합니다.
7. 게임 기회가 남아 있으면 `스페이스키를 눌러 다음 게임을 시작하세요.`라는 안내를 표시합니다.
8. 사용자가 스페이스키를 누르면 벽돌, 공, 컨트롤 바, 점수를 초기화하고 다음 게임을 시작합니다.
9. 3회의 게임 기회를 모두 사용하면 `게임 종료`와 마지막 게임의 최종 점수를 표시하고, 다시 시작할지 안내합니다.
10. 승리하거나 3회의 게임 기회를 모두 사용한 후 스페이스키를 누르면 게임 기회를 3회로 초기화하고 새 게임을 시작합니다.

### 2.6 점수와 상태 표시

- 벽돌 하나를 제거할 때마다 10점을 추가합니다.
- 최고 점수는 630점입니다. 계산식은 `벽돌 63개 × 10점 = 630점`입니다.
- 현재 점수 옆에 남은 벽돌 개수를 괄호 안에 표시합니다. 예: `점수: 100 (남은 벽돌: 53개)`
- 남은 게임 기회를 `남은 기회: 3회` 형식으로 표시합니다.
- 현재 상태는 `대기`, `진행 중`, `기회 종료`, `승리`, `게임 종료`로 표시합니다.
- 다음 게임을 시작하면 점수와 남은 벽돌 개수는 각각 0점과 63개로 초기화합니다.
- 점수는 브라우저를 새로 열거나 새로 고치면 초기화하며 별도로 저장하지 않습니다.

## 3. 파일 구성

```text
02-bricks/
├── 기획서.md
├── brick_game.html
├── brick_game.css
└── brick_game.js
```

- `brick_game.html`: 게임 화면의 구조와 CSS·자바스크립트 파일 연결을 담당합니다.
- `brick_game.css`: 게임 영역, 벽돌, 공, 컨트롤 바, 안내 문구의 모양을 담당합니다.
- `brick_game.js`: 키보드 입력, 공 이동, 충돌 판정, 점수, 승리·패배, 재시작을 담당합니다.

## 4. 구현 방식

- HTML의 `canvas` 요소 하나에 공, 벽돌, 컨트롤 바를 그리는 방식으로 구현합니다.
- 자바스크립트의 `requestAnimationFrame()`을 사용하여 공의 움직임을 반복해서 갱신합니다.
- 별도 라이브러리나 외부 서비스는 사용하지 않습니다.
- 실제 개인정보, 비밀키, 비밀번호, 토큰은 사용하지 않습니다.

## 5. 키보드 조작

| 키 | 동작 |
|---|---|
| 스페이스키 | 첫 게임 시작, 다음 게임 시작 또는 전체 게임 종료 후 재시작 |
| 왼쪽 방향키 | 컨트롤 바를 왼쪽으로 이동 |
| 오른쪽 방향키 | 컨트롤 바를 오른쪽으로 이동 |

- [ ] 1024 × 768 모니터에서 게임 영역이 스크롤 없이 표시됩니다.

- [ ] 스페이스키를 누르기 전까지 공이 움직이지 않습니다.

- [ ] 점수 옆에 남은 벽돌 개수가 표시되고, 벽돌 제거 시 개수가 1개씩 줄어듭니다.
- [ ] 남은 게임 기회가 표시되고, 공을 놓칠 때마다 1회씩 줄어듭니다.
- [ ] 게임 기회가 남아 있으면 스페이스키로 다음 게임을 시작할 수 있습니다.

- [ ] 승리 또는 전체 게임 종료 후 스페이스키로 게임 기회를 포함한 모든 상태를 초기화하고 다시 시작할 수 있습니다.
- [ ] 브라우저 개발자 도구의 콘솔에 자바스크립트 오류가 표시되지 않습니다.

## 8. 확정 전 확인을 권장하는 선택 사항

다음 항목은 현재 기획서에서 기본값으로 확정했지만, 제작 전에 필요하면 변경할 수 있습니다.

- 벽돌의 `100px`을 가로 길이로 해석하고 세로 길이를 `30px`로 정했습니다.
- 한 층의 벽돌 수는 1024 × 768 화면 배치를 고려하여 9개로 정했습니다.
- 컨트롤 바의 `150px`을 가로 길이로 해석하고 세로 길이를 `15px`로 정했습니다.
- 조작 방법은 왼쪽·오른쪽 방향키로 정했습니다.
- 게임 기회는 총 3회이며, 공을 놓칠 때마다 1회씩 차감합니다.
- 공 색상은 요청에 없으므로 화면에서 구분하기 쉬운 파란색으로 정했습니다.
- 난이도 증가 없이 공의 속도를 일정하게 유지합니다.
