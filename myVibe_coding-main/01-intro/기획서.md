# 자기소개 웹페이지 기획서

## 1. 프로젝트 개요

- 프로젝트명: 처음 만난 친구들을 위한 자기소개 웹페이지
- 목적: 수업에서 처음 만난 친구들이 가상 인물의 기본 정보와 관심사를 쉽게 알 수 있도록 소개합니다.
- 대상 사용자: 같은 수업을 듣는 대학생
- 제작 범위: 한 화면에서 주요 내용을 확인할 수 있는 단일 웹페이지

## 2. 가상 인물 설정

- 이름(별명): 도토리
- 나이: 22세
- 성별: 남성
- 신분: 대학교 2학년
- 전공: 디지털콘텐츠학과
- 성격: 처음에는 조용하지만 친해지면 이야기를 많이 합니다.
- 취미: 농구 경기 보기, 사진 찍기, 카페 탐방
- 관심 분야: 웹 디자인, 영상 편집, 인공지능
- 좋아하는 음식: 돈가스와 떡볶이
- 대학 생활 목표: 다양한 사람을 만나고 팀 프로젝트 경험을 쌓는 것입니다.
- 인사말: “처음이라 조금 어색하지만 편하게 인사해 주세요!”

> 위 정보는 실습을 위해 만든 가상 정보입니다. 실제 이름, 학번, 연락처, 이메일은 사용하지 않습니다.

## 3. 화면 구성

### 3.1 상단 소개 영역

- 페이지 제목
- 가상 인물의 별명
- 짧은 인사말
- 가상 인물을 나타내는 이모지 또는 직접 만든 이미지

### 3.2 기본 정보 영역

- 학년과 전공
- 성격
- 대학 생활 목표

### 3.3 취미와 관심사 영역

- 취미 3개
- 관심 분야 3개
- 좋아하는 음식

### 3.4 마무리 영역

- 친구들에게 전하는 한마디
- 페이지가 가상 인물을 소개한다는 안내 문구

## 4. 디자인 방향

- 전체 분위기: 밝고 편안한 대학생 자기소개 화면
- 주요 색상: 초록색
- 배경 색상: 연한 아이보리색 또는 흰색
- 글자 색상: 진한 회색
- 배치 방식: 내용을 카드 형태로 나누어 한눈에 구분되도록 구성
- 화면 대응: 컴퓨터와 스마트폰에서 내용이 잘리지 않도록 제작

## 5. 사용할 기술

- HTML: 제목, 문단, 목록 등 웹페이지의 내용과 구조 작성
- CSS: 색상, 글자 크기, 여백, 카드 모양 등 화면 꾸미기
- JavaScript: 첫 실습에서는 사용하지 않음
- 외부 서비스: 사용하지 않음

## 6. 파일 구성

```text
01-intro/
├─ 기획서.md
├─ index.html
└─ style.css
```

- `index.html`: 자기소개 내용과 화면 구조
- `style.css`: 색상과 배치 등 디자인
- 이미지가 필요하면 저작권 문제가 없는 직접 제작 이미지 또는 이모지를 사용합니다.

## 7. 구현 단계

### 1단계: HTML로 내용 구성

- `index.html`을 만듭니다.
- 상단 소개, 기본 정보, 취미와 관심사, 마무리 영역을 작성합니다.
- 모든 화면 문구는 한국어로 작성합니다.

### 2단계: CSS로 화면 꾸미기

- `style.css`를 만들고 `index.html`에 연결합니다.
- 배경색, 글자색, 여백과 카드 모양을 지정합니다.
- 스마트폰에서도 읽기 편하도록 화면 크기에 맞게 조정합니다.

### 3단계: 실행 및 확인

- 웹 브라우저에서 `index.html`을 엽니다.
- 글자가 깨지거나 내용이 잘리는지 확인합니다.
- 컴퓨터 화면과 좁은 스마트폰 화면에서 각각 확인합니다.

## 8. 완료 기준

- [ ] `index.html`과 `style.css`가 `01-intro` 폴더에 있습니다.
- [ ] `index.html`을 열면 오류 없이 자기소개 화면이 나타납니다.
- [ ] 별명, 학년, 전공, 성격, 취미, 관심 분야, 목표와 인사말이 표시됩니다.
- [ ] 실제 개인정보가 포함되지 않습니다.
- [ ] 모든 화면 문구와 코드 주석이 한국어로 작성되어 있습니다.
- [ ] 컴퓨터와 스마트폰 화면에서 가로 스크롤 없이 내용을 읽을 수 있습니다.
- [ ] 외부 서비스나 인터넷 연결 없이 실행됩니다.

## 9. 제외 범위 및 주의사항

- 회원가입, 로그인, 게시판과 데이터 저장 기능은 만들지 않습니다.
- 실제 연락처, 이메일, 학번과 사진을 사용하지 않습니다.
- 기능을 추가하려면 기획서를 먼저 수정한 후 구현합니다.
