# 기획서: 자기소개 웹페이지

## 누가 쓰나

수업에서 처음 만난 친구들

## 만들 것

가상의 인물을 소개하는 한 페이지짜리 웹페이지

## 기능

1. 별명과 한 줄 소개
   - 별명은 웹페이지 제작을 요청할 때 정한다.
   - 실제 인물이 아닌 가상의 인물임을 알린다.
2. 좋아하는 것 3가지
3. 버튼을 누르면 배경색이 바뀜

## 조건

- `index.html`에 HTML, CSS, JavaScript를 작성하고 생성 이미지는 `images/`에 저장
- 외부 라이브러리, 서버, 데이터베이스는 사용하지 않음
- 실명과 연락처는 넣지 않음
- 취향을 표현하는 가상의 정물 이미지는 사용 가능
- 누가 봐도 가상임을 알 수 있는 정보만 사용

## 완료 기준

- [ ] `01-intro/index.html`을 더블클릭하면 브라우저에서 바로 열린다.
- [ ] 별명과 한 줄 소개가 화면에 보인다.
- [ ] 좋아하는 것 3가지가 화면에 보인다.
- [ ] 버튼을 누르면 배경색이 바뀐다.
- [ ] 실명, 연락처, 실제 인물 사진이 들어 있지 않다.
- [ ] 실제 인물이나 저작권 캐릭터를 직접 묘사한 이미지가 없다.
- [ ] 외부 라이브러리, 서버, 데이터베이스를 사용하지 않는다.
